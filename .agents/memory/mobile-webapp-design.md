---
name: Mobile Telegram WebApp design
description: Design and validate the game surface for narrow phone screens before desktop layouts.
---

Telegram WebApp game screens should be designed around a narrow phone viewport first, with safe-area padding, thumb-sized controls, horizontal hand scrolling, and explicit opponent/bot status.

**Why:** A wide desktop preview can make a layout appear usable while hiding overflow, cramped card hands, missing avatar context, and controls that are hard to reach on mobile.

**How to apply:** Validate onboarding, mode/deck selection, lobby, table, bot-thinking state, color choice, and end-of-match states at phone width before polishing larger breakpoints.
